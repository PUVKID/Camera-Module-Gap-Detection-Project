### LEVEL 1 · 부품 정렬에서 갭 길이까지

사진이 기울어 있으면 같은 위치의 틈도 다른 곳에서 재게 됩니다. **기준점 정렬→측정 영역 선택→흑백 변환→길이 읽기** 순서로 보세요. 좋은 화질과 정확한 길이는 같은 뜻이 아니므로 마지막에는 실제 측정의 흔들림을 확인합니다.

| <a id="layout18-table-1-row-2"></a> 6개 ROI·샘플 X 좌표 | ROI는 사진 전체 중 실제로 길이를 잴 작은 영역입니다.<br>원고는 6개 ROI와 ROI별 6개 샘플 X 좌표를 설명합니다.<br>단순히 전체 사진에 줄 여섯 개를 긋는 것과 구분합니다. |
| <a id="layout18-table-1-row-3"></a> 이진화·1D 투영·검정 연속 구간 | 밝기를 흰색/검정으로 나눈 뒤 지정 좌표에서 픽셀의 연속 구간을 읽어 갭 길이를 구합니다. 1D 투영은 영역 정보를 한 축으로 모아 경계를 살피는 방법입니다. |
| <a id="layout18-table-1-row-4"></a> 공간·주파수·비국소 필터 | 주변 픽셀, 주파수 성분, 닮은 무늬를 이용하는 필터군을 비교합니다.<br>반사·잡음·국부 밝기가 이진화 경계를 흐리는 문제를 다룹니다. |

## 연구 목적

이 연구는 이진화 영상 자체의 모양뿐 아니라 ROI에서 얻는 갭 길이의 안정성을 비교합니다.

현재 원문을 읽으면서 초기·최종 HWP·사진 포함 최종의 편집 차이를 아래 비교와 함께 확인할 수 있습니다.

<a name="usage"></a>

<a id="-읽고-활용하는-순서"></a>

## 원고 읽기

1. 연구 질문에서 갭 길이 측정의 안정성과 이진화 품질이 어떻게 연결되는지 읽습니다.
2. 키포인트 정렬→ROI→필터→이진화→샘플라인 측정 순서로 처리 방법을 따라갑니다.
3. 필터별 표·예시 그림에서 길이 편차와 누락·이상치 비율을 함께 확인합니다.
4. 영상 품질 지표와 실제 측정 신뢰성·처리시간이 같은 지표가 아님을 구분해 결과를 읽습니다.

<a name="results"></a>

<a id="-결과를-읽는-방법"></a>

## 결과와 해석

갭 평균만으로 조건을 고르지 않고 표준 편차·누락률·이상치율을 함께 읽습니다. PSNR·SSIM이 높아도 갭 경계를 더 안정적으로 찾는지는 측정 결과로 따로 확인합니다.

원고의 장수·시간·필터 서술에는 내부 차이가 있습니다. 이 차이는 원고를 읽는 제약으로 설명하고 숫자를 새 측정값으로 정정하지 않았습니다.
