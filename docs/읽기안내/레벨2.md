<a id="guide-problem"></a>

## 문제와 주요 기능

ROI는 사진 전체 중 갭을 재는 부분입니다. 키포인트 정렬로 위치를 맞추고, 필터로 잡음을 줄인 뒤 이진화 경계를 찾습니다. 색이 깨끗한 영상과 측정이 안정적인 영상을 구분합니다.

<a id="guide-flow"></a>

## 입력·처리·출력

YOLO의 left_top·right_top 키포인트로 회전·위치를 정렬합니다. ROI에 필터와 이진화를 적용하고 6개 샘플 라인의 1D 투영을 읽습니다. 투영은 한 방향의 픽셀 정보를 줄 형태로 모아 경계를 찾는 과정입니다.

<a id="guide-practice"></a>

## 실험과 사용 흐름

원고의 질문 →방법 →결과를 따라 읽고 필터 그림과 계측표를 나란히 비교합니다. 초기 원고와 최종 HWP, 사진 포함 HWPX는 편집 단계입니다. 같은 연구의 문서 변화와 새 실험 실행을 나눕니다.

<a id="guide-results"></a>

## 관측 결과와 해석

평균·표준 편차는 길이의 중심과 변동을, 누락률·이상치율은 측정 실패를 설명합니다. PSNR·SSIM은 화질 유사도입니다. 원고의 0.1266 s/image는 필터 처리 시간이며 공장 전체 검사 시간은 아닙니다.

<a id="guide-architecture"></a>

## 구현과 핵심 파일

최종 원고는 방법과 그림, 연구노트는 전처리 개념·Python 예시를 담습니다. 외부 Electronics 논문은 관련 연구입니다. 자체 계측 방법과 외부 저자의 성과를 같은 것으로 합치지 않습니다.

<a id="guide-paper"></a>

## 실제 논문과 원고

원고 차수는 초기, 최종 HWP/PDF, 사진 포함 최종으로 구분합니다. Binarization 연구노트와 Electronics 참고논문은 별도 목적의 자료입니다. 출처와 원저자 표기를 함께 확인합니다.

<a id="guide-limits"></a>

## 조건·실패·미검증 한계

사진이 깨끗해 보이는 것과 틈 측정의 신뢰성은 다릅니다. 원고 내부 수치 차이와 외부 환경 평가 부재를 함께 읽습니다. 참고노트의 예시를 곧바로 생산라인에 연결하는 안내는 아닙니다.

### LEVEL 2 · 부품 정렬에서 갭 길이까지

정렬은 좌표를 맞추고 필터는 밝기·잡음을 다듬으며 이 진화는 갭 경계를 구분합니다. ROI와 샘플 X 좌표가 그 결과를 길이로 연결합니다. **단계마다 해결하는 문제가 달라** 필터 하나의 시각적 효과만으로 전체 측정을 판단하지 않습니다.

| 조건·자료 | 의미와 확인 방법 |
| --- | --- |
| <a id="layout18-table-3-row-1"></a> left_top/right_top 키포인트 | 부품 위의 왼쪽·오른쪽 기준점 두 개를 찾아 회전과 이동을 보정합니다.<br>사진마다 부품이 기울거나 밀려도 같은 자리를 측정하려는 단계입니다. |
| <a id="layout18-table-3-row-2"></a> 6개 ROI·샘플 X 좌표 | ROI는 사진 전체 중 실제로 길이를 잴 작은 영역입니다.<br>원고는 6개 ROI와 ROI별 6개 샘플 X 좌표를 설명합니다.<br>단순히 전체 사진에 줄 여섯 개를 긋는 것과 구분합니다. |
| <a id="layout18-table-3-row-3"></a> 이진화·1D 투영·검정 연속 구간 | 밝기를 흰색/검정으로 나눈 뒤 지정 좌표에서 픽셀의 연속 구간을 읽어 갭 길이를 구합니다. 1D 투영은 영역 정보를 한 축으로 모아 경계를 살피는 방법입니다. |
| <a id="layout18-table-3-row-4"></a> 공간·주파수·비국소 필터 | 주변 픽셀, 주파수 성분, 닮은 무늬를 이용하는 필터군을 비교합니다.<br>반사·잡음·국부 밝기가 이진화 경계를 흐리는 문제를 다룹니다. |

### LEVEL 2·5 픽셀 규칙과 필터 후보 선택

필터로 잡음을 줄인 다음 Sharpen으로 경계를 보완하는 조합을 비교합니다. 평균 차이는 측정 중심의 변화, 표준 편차는 흔들림을 보는 데 쓰입니다. 상위 10% 선택은 원고의 후보 선별 절차이며 보편적인 품질 보증은 아닙니다.

| 조건·자료 | 의미와 확인 방법 |
| --- | --- |
| <a id="layout18-table-4-row-1"></a> 최소 5 픽셀 그룹 | 검정 픽셀의 연속 길이가 최소 5 픽셀인 그룹을 유효 후보로 보는 규칙입니다. |
| <a id="layout18-table-4-row-2"></a> 5 픽셀 이하 간격 병합 | 서로 떨어진 검정 그룹 사이 간격이 5 픽셀 이하이면 합치는 별도 규칙입니다.<br>그룹 최소 길이와 그룹 사이 간격은 다른 값입니다. |
| <a id="layout18-table-4-row-3"></a> 상단·하단의 다른 조건 | 상 단은 Anisotropic 필터·임계값 100, 하단은 Wiener 필터·임계값 130 예시입니다.<br>임계값은 흑백을 나누는 밝기 기준이며 영역별로 다릅니다. |
| <a id="layout18-table-4-row-4"></a> 순차 조합과 후보 정렬 | Fast Global Smoother+Sharpen, Bilateral+Sharpen, Median+Sharpen 등의 결과를 ROI 그룹의 평균 차이와 표준편차 합으로 정렬하고 상위 10% 필터군을 고릅니다. |
| <a id="layout18-table-4-row-5"></a> 경험적 설정 | 5 픽셀은 초기 배치 실험에서 정한 값입니다.<br>통계적으로 모든 환경에서 최적인 값이 아니며 환경별 적응·최적화는 후속 과제입니다. |


<a id="semantic-measurements-level-2"></a>

### LEVEL 2 · 보고 지표와 처리시간의 범위

화질 지표는 전처리가 영상에 주는 영향, 갭 관련 지표는 그 변화가 측정에 주는 영향을 보여 줍니다. 비용은 또 다른 축입니다. 그림과 문단의 조건이 다르면 동일한 실험 결과처럼 이어 붙일 수 없습니다.

| 조건·자료 | 의미와 확인 방법 |
| --- | --- |
| <a id="layout18-table-5-row-1"></a> 초록의 갭 편차 28.6% 감소 | 길이 측정의 편차가 줄었다는 원고 보고입니다.<br>검사 정확도 28.6%나 모든 샘플의 개선율이 아닙니다. |
| <a id="layout18-table-5-row-2"></a> 누락률 3.9→1.2%·이상치율 6.8→2.5% | 누락은 측정을 얻지 못한 비율, 이상치는 비정상 측정 비율입니다.<br>두 실패를 서로 바꾸어 부르지 않습니다. |
| <a id="layout18-table-5-row-3"></a> PSNR 35.2dB·SSIM 0.94 | 영상의 유사도/화질을 보는 원고 보고값입니다.<br>갭 편차·누락률·이상치율처럼 측정 안정성을 직접 평가하는 지표와 구분합니다. |
| <a id="layout18-table-5-row-4"></a> 0.1266 s/image | 한 영상의 필터 처리시간입니다.<br>카메라 입출력·장비 이동 등을 합친 생산라인 전체 지연이 아닙니다. |
