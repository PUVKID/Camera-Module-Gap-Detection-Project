**84 쪽 Binarization 연구노트는 임계값·필터·ROI·프로젝션 관련 개념과 Python 예시를 모은 자료입니다.**

21 쪽 Electronics 논문은 외부 저자의 연구 참고 문헌입니다.

| 주요 구성 | 내용 |
| --- | --- |
| <a id="layout18-table-1-row-1"></a> 이진화 종류 | 전역 임계값·Otsu·적응형·반전·삼진화 등 방법을 비교합니다. |
| <a id="layout18-table-1-row-2"></a> 필터와 ROI | 공간·주파수·BM3D 등 필터와 ROI 내 흰 픽셀의 1D 투영 예시를 읽습니다. |
| <a id="layout18-table-1-row-3"></a> 외부 연구 | 스마트폰 소형 모듈의 구조 결함을 실시간·노이즈 강건 방식으로 분류한 비지도 연구를 참고합니다. |
| <a id="layout18-table-1-row-4"></a> 출처 보존 | 외부 논문의 DOI10.3390/electronics14173455와 CC BY4.0·원 저자 표기를 유지합니다. |


<a id="-이용-순서"></a>

## 이용 순서

1. 노트 앞부분에서 이진화 종류와 필터 분류를 읽습니다.
2. ROI·투영·갭 길이 예시에서 입력과 출력의 의미를 확인합니다.
3. 필요한 코드 예시의 경로·패키지·영상 조건을 따로 준비합니다.
4. 외부 논문의 서론·방법·결과·한계를 읽으며 최종 갭 검출 원고와 문제·평가 기준을 비교합니다.
